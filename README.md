# 🎬 Interfaz Web para Cine

Sitio web de cine desarrollado con HTML, CSS y JavaScript. Incluye múltiples secciones: cartelera, próximos estrenos, tráilers, caramelería, comida, horarios, registro de usuario y recuperación de contraseña.

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla)

## ✨ Funcionalidades

- Página principal con tráilers de películas en exhibición.
- Sección de cartelera y próximos estrenos.
- Módulo de caramelería y comida con presentación de productos.
- Sección de horarios de funciones.
- Formulario de registro de usuario.
- Página de recuperación de contraseña (olvidó su contraseña).
- Menú hamburguesa funcional para dispositivos móviles.
- Animaciones y transiciones con JavaScript.
- Mostrar/ocultar contenido dinámico.
- Diseño responsive adaptable a distintos tamaños de pantalla.
